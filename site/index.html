02
CAPABILITIES

Everything a CLI needs, nothing it does not.

Argon is deliberately small. It covers the common cases with a stable, readable API and leaves application logic to your program.

01 / FLAGS

Long, short, counted.

Define --verbose and -v once. Negatable flags accept --no-color. Count flags turn -vvv into the number three.

02 / OPTIONS

Typed, with defaults.

String, integer, float and boolean options. Every value is checked before it reaches your program.

03 / POSITIONALS

Required, optional, rest.

A positional can be required, optional, or collect the rest of the line. The -- marker stops option parsing cleanly.

04 / VALIDATION

Rules, not guesses.

OneOf, Range, MinLength and MaxLength reject bad input with a stable error kind and a useful message.

05 / SUBCOMMANDS

One level, fully featured.

Each command owns its options and arguments. Global options work before or after the command name.

06 / HELP + COMPLETION

Paper that answers back.

Aligned help with defaults, arguments and commands, plus ready-made Bash and Zsh completion scripts.

03
QUICK START

Three steps to a working interface.

Keep the facade and the package folder together. Include the facade. Describe the command line once.

01
INCLUDE THE FACADE

Copy src/argon.salam and the src/argon/ folder into your project. The facade includes the package files for you.

02
DESCRIBE THE INTERFACE

Create a parser, add flags and options, add a positional, and let Argon generate help and validation.

03
PARSE AND READ

Call ParseProcess for os.Args or Parse for a vector. Check Ok, print Help when asked, and read typed values.

FIELD NOTE

Salam's import keyword is for the standard library. Local packages are joined with include; that is why the facade exists.

main.salam
// lang: en
package main

include argon "src/argon.salam"

func main:
    mut p := argon.New("my-app", "A sample Salam application")
    p.SetVersion("1.0.0")
    p.Flag("verbose", "v", "Enable verbose output")
    p.StrOption("output", "o", "Output file path", "build.txt")
    p.IntOption("count", "c", "Number of items", 1)
    p.Positional("name", "Name to greet")
    defer p.Free()

    res := p.ParseProcess()
    defer res.Free()

    if res.HelpWanted():
        print p.Help()
        ret argon.ArgExitOK
    end
    if res.VersionWanted():
        println p.VersionLine()
        ret argon.ArgExitOK
    end
    if not res.Ok():
        printerrln res.Error()
        ret res.ExitCode()
    end

    println "hello,", res.Str("name")
    println "count:", res.Int("count")
    ret argon.ArgExitOK
end

04
INSTALL / BUILD

A source file, a folder, and a make target.

Argon has no package manager step and no runtime configuration. The repository carries the library, examples, tests and this site source.

REQUIREMENTS

Salam 0.6.2 or newer and a working C toolchain. The Makefile prefers the C backend on older releases, where the LLVM backend does not lower cross-package structs.

export PATH="$HOME/.salam/bin:$PATH"
export SALAM_STD="$HOME/.salam/bin/std"
MAKE TARGETS
make build     # compile the demo
make test      # 189 assertions
make examples  # run four real CLIs
make format-check
make site      # rebuild this page
05
API / BUILDERS

Describe the command line once.

The parser is a builder. Add definitions in the order you want them to appear in help, then parse. Definitions never throw; a bad definition becomes a definition error on the next parse.

Flags and options

Every builder takes a long name, a one-character short name, and a help line. Use an empty short string when you only want the long form.

CALLVALUENOTES
p.Flag(name, short, help)bool--verbose and -v. False unless given.
p.NegatableFlag(name, short, help, default)bool--color, --no-color, --color=false.
p.CountFlag(name, short, help)intRepeats: -vvv gives 3. --verbose=2 is rejected.
p.StrOption(name, short, help, default)strThe default is shown in help and used when the option is absent.
p.IntOption(name, short, help, default)i64Decimal, optional sign. Bad text is never silently zero.
p.FloatOption(name, short, help, default)f64Accepts a decimal point and an exponent.
p.BoolOption(name, short, help, default)bool--dry, --no-dry, --dry=false.
p.MultiOption(name, short, help)Vector<str>Repeatable: --include a --include b.

Positionals

A rest argument must be last. Required arguments are checked after option validation.

CALLSHAPENOTES
p.Positional(name, help)<name>Exactly one value, required.
p.OptionalPositional(name, help)[name]Zero or one value.
p.RestPositional(name, help, min)[name...]Collects the rest. min 0 or more; min 1 is required.
p.AddArgument(spec)ArgumentSpecAdvanced construction through NewArgument and friends.

Validation rules

Rules live on the option spec. Build a spec, configure it, then add it to the parser or command.

RULEERROR KINDBEHAVIOUR
Require()missing-requiredThe option must appear; its default is removed from help.
OneOf(value)not-allowedAppend allowed values; the message lists them.
Range(lo, hi)out-of-rangeInclusive numeric range for int and float.
MinLength(n)too-shortCounts Unicode characters, not bytes.
MaxLength(n)too-longCounts Unicode characters, not bytes.
AllowRepeat()duplicate-optionWithout it, a value option may appear only once.
Hide()-Keeps the item parseable but out of help and completion.
advanced-validation.salam
mut mode := argon.NewStrOption("mode", "m", "Output mode", "fast")
mode.OneOf("fast")
mode.OneOf("slow")
mode.MinLength(2)
mode.MaxLength(8)
p.AddOption(mode)

mut level := argon.NewIntOption("level", "l", "Level", 1)
level.Range(1, 9)
p.AddOption(level)

mut tag := argon.NewStrOption("tag", "t", "Tag", "")
tag.Require()
p.AddOption(tag)

mut include := argon.NewMultiOption("include", "I", "Include path")
include.AllowRepeat()
p.AddOption(include)
06
API / RESULTS

Read values like a typechecker is watching.

A parse returns a Result. The result owns its values; free it when you are done. Getters return defaults when an option is absent and are only meaningful after Ok().

GETTERTYPEUSE
res.Ok()boolThe parse succeeded.
res.HelpWanted()bool--help or -h was given.
res.VersionWanted()bool--version was given.
res.Command()strSelected subcommand, or empty.
res.Str(name)strFirst value or the default.
res.Int(name)i64Integer value, already checked.
res.Float(name)f64Float value, already checked.
res.Bool(name)boolTrue when set, or the default.
res.Num(name)intOccurrence count of a count flag.
res.IsSet(name)boolTrue only when given, not for a default.
res.ValueCount(name)intNumber of stored values.
res.ValueAt(name, i)strOne stored value, or empty.
res.Strs / Ints / Floats / BoolsVectorAllocating copies. Free them.
res.Extras()Vector<str>Unknown positionals when AllowExtras is on.
res.ErrorKind / ErrorMessage / ErrorstrStable kind, raw message, formatted message.
res.ExitCode()int0 for success, help or version; 2 for usage errors.
result.salam
res := p.ParseProcess()
defer res.Free()
defer p.Free()

if res.HelpWanted():
    print p.HelpFor(res.Command())
    ret argon.ArgExitOK
end
if res.VersionWanted():
    println p.VersionLine()
    ret argon.ArgExitOK
end
if not res.Ok():
    printerrln res.Error()
    ret res.ExitCode()
end

println "name:  ", res.Str("name")
println "count: ", res.Int("count")
println "ratio: ", res.Float("ratio")
println "verbose:", res.Bool("verbose")
MEMORY NOTE

Parser.Free frees definitions; Result.Free frees parsed values. The list getters Strs, Ints, Floats and Bools return new vectors and must be freed too.

07
SUBCOMMANDS / TOOLING

Commands with their own paperwork.

Each command owns its arguments and options. Global options work before or after the command name. Command help includes a Global options section.

subcommands.salam
mut p := argon.New("project", "Project tool")
p.Flag("verbose", "v", "Print more details")

build := argon.NewCommand("build", "Build the project")
build.Flag("release", "r", "Release build")
build.Positional("target", "Build target")
p.AddCommand(build)

serve := argon.NewCommand("serve", "Serve the project")
mut port := argon.NewIntOption("port", "p", "Port", 8080)
port.Range(1, 65535)
serve.AddOption(port)
p.AddCommand(serve)

res := p.ParseProcess()
defer res.Free()
defer p.Free()

if res.Command() == "build":
    println "target:", res.Str("target")
    println "release:", res.Bool("release")
end
COMMAND NOTES
→Use res.Command() to branch, then the same getters.
→A global option is accepted before and after the command.
→cmd.Hide() keeps a command out of help and completion.
→Command options cannot reuse a global option name.
→One level only. Nested subcommands are not implemented.
COMPLETION + COLOUR
print p.Completion("bash")
print p.Completion("zsh")

p.SetColor(argon.ArgColorNever)
p.SetColor(argon.ArgColorAlways)

Auto colour is the default and only appears on a terminal. NO_COLOR and ARGON_COLOR=never disable it.

09
ERRORS

Bad input is a report, not a crash.

Every failure has a stable kind, a readable message and a help hint. The parser never throws or aborts on user input.

errors.tty
$ my-app --count nope Ada
error: invalid int value for '--count': 'nope'
try 'my-app --help' for more information.

$ my-app --colour
error: unknown option '--colour'
try 'my-app --help' for more information.

$ my-app --mode=other Ada
error: invalid value 'other' for '--mode' (allowed: fast, slow)
try 'my-app --help' for more information.

EXIT CODES

0 for success, help or version. 2 for usage errors. Your main function can return res.ExitCode() directly.

10
KNOWN LIMITS

What this manual does not promise.

A small library should say where it ends. These are the deliberate boundaries of version 1.0.0.

Subcommands are one level deep.

A command may have arguments, flags and options, but not another command. Nested command trees are future work.

Completion covers names, not values.

Bash and Zsh scripts complete command and option names. Value providers would need a different API and are not part of this version.

A string value starting with - needs the equals form.

Write --output=-file instead of --output -file. Numeric options accept a separate negative value, such as --level -5.

A parser is not shared between threads.

Definitions are mutable while you build them. Create one parser per thread or finish building before sharing reads.

Salam 0.5.4 lowers cross-package structs only on the C backend.

On 0.5.4 the LLVM backend prints a fallback warning and switches to C. The Makefile uses BACKEND=c by default. Salam 0.6.2 and newer may handle the LLVM path without a fallback.

Not every release ships a salam test subcommand.

This project uses a normal executable test program, so make test works on every compiler version. The test exits with the number of failed assertions.
